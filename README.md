# Auréa

Application d'initiation à la foi catholique pour les vrais débutants : courtes cartes, déblocage progressif, glossaire cliquable, prière dès le premier jour, accompagnement humain par les paroisses.

- `web/` : prototype web (HTML/CSS/JS, sans dépendance). Ouvrir `web/index.html` dans un navigateur.
- `docs/blueprint.md` : vision, parcours, modules, architecture, légal.
- `docs/recherche-temoignages.md` : synthèse de recherche (sources à vérifier).

Statut : prototype. Les contenus doctrinaux sont des brouillons à faire relire par un théologien.
